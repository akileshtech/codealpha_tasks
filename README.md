# CodeAlpha Machine Learning Internship 🚀

This repository contains my Machine Learning projects completed
as part of my CodeAlpha internship tasks.

## 📌 Task 1: Handwritten Character Recognition

### Description
A machine learning project that recognizes handwritten digits
using the MNIST dataset and a Convolutional Neural Network (CNN).

### Technologies
- Python
- TensorFlow / Keras
- NumPy
- Streamlit

### Features
- Recognizes handwritten digits.
- Uses a trained CNN model.
- Provides a user-friendly interface.

### Model Performance
Test accuracy: 98.94%

## 📌 Task 2: Credit Scoring Model

### Description
A machine learning project that predicts customer credit risk
using the German Credit dataset.

### Algorithms
- Logistic Regression
- Random Forest Classifier

### Technologies
- Python
- Pandas
- NumPy
- Scikit-learn
- Joblib
- Streamlit

### Features
- Accepts customer financial details.
- Predicts good or bad credit risk.
- Displays estimated bad-credit-risk probability.
